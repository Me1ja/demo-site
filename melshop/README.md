# MelShop — тема для OpenCart 3 / ocStore 3

Універсальна тема з модулем налаштувань «MelShop — налаштування теми».

- `upload/` — файли для копіювання в корінь магазину (admin/, catalog/)
- `ms_install.php` — встановлення з консолі: `php ms_install.php /шлях/до/public_html`

Тема перевизначає лише потрібні шаблони, решта береться зі стандартної теми, тому сторонні модулі працюють як зі стандартною темою.
